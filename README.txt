MUM FLORENCE - build the app

1. In your GitHub repository, open "Add file" > "Upload files" and drag in ONLY the file
   MumFlorence.zip (do not unzip it). Commit.
2. Replace the workflow: Code tab > .github > workflows > main.yml > pencil icon > select all >
   paste the new build text from the chat > Commit.
3. Actions tab: wait for the green tick (about 8 minutes). Then Releases > download app-debug.apk.
4. Install it, open Mum Florence, tap "Set up everything".
